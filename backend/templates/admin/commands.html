🌿 Seed Election Data

One-time cold-start seed. Runs Census → Google Civic → Congress → FEC in order. Allow 5–15 minutes. Open States is opt-in due to rate limits.

Create and run seed job (first time only):

gcloud beta run jobs create civicmirror-seed \
  --image us-central1-docker.pkg.dev/civicmirror-2026/civicmirror-images/backend:latest \
  --region us-central1 --project civicmirror-2026 \
  --set-env-vars DJANGO_SETTINGS_MODULE=config.settings.prod \
  --set-secrets DATABASE_URL=DATABASE_URL:latest \
  --set-secrets DJANGO_SECRET_KEY=DJANGO_SECRET_KEY:latest \
  --add-cloudsql-instances civicmirror-2026:us-central1:civicmirror-db \
  --service-account cloudrun-runtime@civicmirror-2026.iam.gserviceaccount.com \
  --command "python,manage.py,seed_election_data" \
  --execute-now --wait

Re-run existing seed job:

gcloud beta run jobs execute civicmirror-seed \
  --region us-central1 --project civicmirror-2026 --wait

Seed including Open States (rate-limited — use sparingly):

gcloud beta run jobs update civicmirror-seed \
  --command "python,manage.py,seed_election_data,--include-openstates" \
  --region us-central1 --project civicmirror-2026

gcloud beta run jobs execute civicmirror-seed \
  --region us-central1 --project civicmirror-2026 --wait

🗃 Database Migrations

Migrations run automatically on every deploy via CI/CD. Use this only when a manual run is needed. 

gcloud run jobs execute civicmirror-migrate \
  --region us-central1 --project civicmirror-2026 --wait

👤 Admin User Management

Create or update the Django admin superuser. Replace USERNAME, EMAIL, and PASSWORD before running.

Execute the pre-configured superuser job:

gcloud beta run jobs execute civicmirror-createsuperuser \
  --region us-central1 --project civicmirror-2026 --wait

Update credentials then run:

gcloud beta run jobs update civicmirror-createsuperuser \
  --update-env-vars DJANGO_SUPERUSER_USERNAME=USERNAME \
  --update-env-vars DJANGO_SUPERUSER_EMAIL=EMAIL \
  --update-env-vars DJANGO_SUPERUSER_PASSWORD=PASSWORD \
  --region us-central1 --project civicmirror-2026

gcloud beta run jobs execute civicmirror-createsuperuser \
  --region us-central1 --project civicmirror-2026 --wait

📋 Live Logs

Tail live logs from the backend API or frontend nginx. Press Ctrl+C to stop.

Backend (Django / Gunicorn — API calls, errors):

gcloud run services logs tail civicmirror-backend \
  --region us-central1 --project civicmirror-2026

Frontend (nginx access logs):

gcloud run services logs tail civicmirror-frontend \
  --region us-central1 --project civicmirror-2026

🚀 Deploy

Trigger a full deployment via GitHub Actions. Builds backend + frontend images, runs migrations, and updates Cloud Run services. 

gh workflow run deploy.yml --repo tokendad/CivicMirror
